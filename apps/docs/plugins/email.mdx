---
title: "@pylonsync/email"
description: "Transactional email — provider-agnostic, declarative templates, suppression list, signed-webhook delivery-event ingest."
---

Replaces the dead `EmailPlugin` Rust shell. Wraps Resend / Postmark / SES / SMTP / log as configurable providers. Declarative template registry, suppression list on bounce, idempotency keys, scheduled sends.

## Install

```bash
bun add @pylonsync/email
```

## Config

```ts
import { email, sendEmail } from "@pylonsync/email";

export const mail = email({
  provider: "resend",
  from: "Acme <hello@acme.com>",
  templates: {
    welcome: {
      subject: (v) => `Welcome to Acme, ${v.name}`,
      render: (v) => ({
        html: `<h1>Hi ${v.name}</h1>`,
        text: `Hi ${v.name}`,
      }),
    },
    passwordReset: {
      subject: "Reset your password",
      text: (v) => `Click here: ${v.url}`,
    },
  },
  hooks: {
    onBounced: async (ctx, { recipient }) => {
      // suppression auto-added; emit audit event
    },
  },
});
```

## Required env

| Variable | Purpose |
| --- | --- |
| `RESEND_API_KEY` / `POSTMARK_API_KEY` / `SES_API_KEY` | Provider auth. |
| `RESEND_WEBHOOK_SECRET` | Delivery-event webhook (svix-style). |

## Sending

```ts
// functions/inviteMember.ts
import { sendEmail } from "@pylonsync/email";
import { mail } from "../mail-config";

export default action({
  args: { email: v.string(), inviteToken: v.string() },
  async handler(ctx, args) {
    await sendEmail(ctx, mail.config, {
      template: "passwordReset",
      to: args.email,
      vars: { url: `https://app.acme.com/reset?token=${args.inviteToken}` },
    });
  },
});
```

## Providers

| Provider | Notes |
| --- | --- |
| `resend` | API + Svix-signed webhooks. |
| `postmark` | API + basic-auth webhooks (per Postmark convention). |
| `ses` | Stub — landing soon. |
| `smtp` | Raw SMTP — useful for self-hosted. |
| `log` | Console output. Dev-mode fallback when no real provider is configured. |

## Lifecycle hooks

| Hook | Fires |
| --- | --- |
| `beforeSend` | Before every dispatch — can throw to abort. |
| `onSent` | After the provider returns a message id. |
| `onDelivered` | Webhook `delivered` event. |
| `onBounced` | Webhook `bounced` event. Default behavior also suppresses the recipient. |
| `onComplained` | Webhook spam-complaint event. Also suppresses. |
| `onOpened` / `onClicked` | Tracking-pixel events. Requires explicit GDPR opt-in in EU/UK. |

## Idempotency

Every `sendEmail()` call computes an idempotency key from `${template}:${to}:hash(vars)` if you don't supply one. Provider-level dedup (Resend/Postmark both honor this) prevents duplicates from retry loops.

## Suppression

`cfg.isSuppressed` is consulted before every send. The plugin doesn't ship a default — apps wire it to their own `EmailSuppression` entity:

```ts
email({
  ...,
  isSuppressed: async (ctx, { email }) => {
    const rows = await ctx.runQuery("findSuppression", { email });
    return rows.length > 0;
  },
});
```

Pair with `onBounced` / `onComplained` hooks to auto-populate the suppression table.
