description: "Append-only event store for compliance, SIEM forwarding, and admin transparency."
---

WorkOS-style audit log schema. Append-only entity, idempotent writes, configurable streaming destinations (webhook / Datadog), optional retention pruning.

## Install

```bash
bun add @pylonsync/audit-log
```

## Config

```ts
import { auditLog, webhookDestination, datadogDestination, logEvent } from "@pylonsync/audit-log";

export const audit = auditLog({
  retentionDays: 365,
  destinations: [
    webhookDestination({
      url: "https://siem.acme.com/events",
      secret: process.env.SIEM_WEBHOOK_SECRET!,
    }),
    datadogDestination({
      apiKey: process.env.DATADOG_API_KEY!,
      service: "myapp",
    }),
  ],
});

export default app({
  entities: [...audit.manifest.entities],
  policies: [...audit.manifest.policies],
});
```

## Emit events

```ts
// functions/deleteProject.ts
import { logEvent } from "@pylonsync/audit-log";
import { audit } from "../audit-config";

export default mutation({
  args: { projectId: v.id("Project") },
  async handler(ctx, args) {
    const project = await ctx.db.get("Project", args.projectId);
    await ctx.db.delete("Project", args.projectId);
    await logEvent(ctx, audit.config, {
      actor: { id: ctx.auth.userId!, type: "user" },
      action: "project.deleted",
      targets: [{ id: args.projectId, type: "project", name: project?.name }],
      metadata: { reason: "user_initiated" },
    });
  },
});
```

## Schema

The manifest fragment ships an `AuditEvent` entity with WorkOS-compatible columns:

| Column | |
| --- | --- |
| `idempotencyKey` | Auto-computed `${actor.id}:${action}:${target-ids}:${occurredAt}` if not supplied. |
| `organizationId` | Tenant scope. Default: `ctx.auth.tenantId`. |
| `actor` | JSON `{id, type, name?, metadata?}`. |
| `action` | Dot-namespaced (`project.deleted`, `org.transferred`). |
| `targets` | JSON array of `{id, type, name?, metadata?}`. |
| `context` | JSON `{ipAddress?, userAgent?}` — auto-stamped from `ctx.request.headers`. |
| `metadata` | App-specific JSON. |
| `occurredAt` | ISO-8601. |

Policy: append-only. Tenant-scoped reads + admin-bypass. No update / no delete except via the `pruneAuditEvents()` admin-only mutation.

## Streaming destinations

```ts
import { webhookDestination, datadogDestination } from "@pylonsync/audit-log";
```

| Destination | Spec |
| --- | --- |
| `webhookDestination({ url, secret })` | HMAC-SHA256 signed POST per event. Receiver verifies via `X-Pylon-Audit-Signature` header. |
| `datadogDestination({ apiKey, region?, service? })` | Datadog Logs ingest. Maps `action` → service, attaches `ddtags`. |

Destination errors are caught + logged; they NEVER fail the primary persistence write. Audit logs must reliably persist even when SIEM ingest is degraded.

## Retention

The plugin doesn't auto-prune. Apps wire a cron to call `pruneAuditEvents({ cutoffISO })` with the retention boundary. Required admin auth (`ctx.auth.isAdmin`).
